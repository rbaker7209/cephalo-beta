# cephalo-beta
A lightweight Debian based Linux distro


I dont intend for anyone else to read this just yet, so please excuse my neurodivergent asf rambling, if the currents of the web have taken your surf here.

Cephalo is a Debian based  OS, built to be customizable, efficient, and easy to use, but without sacrificing optimization or compatability.
While this is somewhat of a self contradictory goal, I hope that this reaches a happy middle. 

current headliner features are:

1. ultra light (388 mb as of writing) installer iso, allowing for quicker installs on horrid flash drives.
2. automated optimization, where the OS configures itself to best fit your hardware, not the opposite.
3. wayland, labwc, and waybar providing a light, but comfortable and usable interface.
4. easy ways to customize the distro, both during and after installation. (this is a bit sparse as of now, im working on it)

one fair warning, this is not a commercial OS just yet. I'd love for it to be one day, but I'm one rando making an entire distro, theres gonna be potholes in the roadmap for a fair while. ye have been warned.
